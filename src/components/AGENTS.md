# src/components

Each directory here is one component, or a small family of them (`Skeleton/`).

## New components need stories

- A new component ships with a `<Name>.stories.tsx` in its own directory, in the
  same PR.
- A change to a component's props or states updates its stories too.
- How to write them: read `docs/storybook.md` (at the repository root) before
  writing or editing a `*.stories.tsx` file.
